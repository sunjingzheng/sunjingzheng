## 关于

用 AI 解决具体问题 —— 从医学影像的分割与重建，到景区里的数字人导游。

- **医学影像 AI**：论文复现与工程化。Synapse 多器官分割、PET 重建，在意的是可复现的评测口径，而不只是跑通脚本。
- **智能导览**：数字人讲解、语音合成与路线推荐。Vue 3 前端，Python 服务端，端到端自己搭。
- **AI 工具链**：把文献调研、实验、写作、配图这套科研流程，沉淀成可复用的 Skills。
